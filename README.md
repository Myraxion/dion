# Dion (descript.ion CLI)

Dion 是一个 Windows 原生命令行工具，用于查看、列出、设置和删除文件与文件夹的备注，与 Total Commander 的带 BOM UTF-8 `descript.ion` 格式互操作。

## 核心特性

- **单文件运行**：适用于 Windows 10/11 x64，无需安装 Rust 或额外运行库；实测 exe 约 346.5 KiB。
- **四个基础命令**：查看单条备注、列出目录备注、设置或覆盖备注、显式删除备注。
- **列表展示**：目录优先、名称自然排序，默认双栏对齐，`--long`（`-l`）单栏展示完整正文，`--recursive`（`-r`）汇总子目录备注。
- **Unicode 与多行**：支持中文、Emoji、含空格的名称和多行正文，保留缩进、首尾空白和空行。
- **局部修改**：保留其他记录的原始字节与顺序；设置相同内容时不写文件。
- **脚本友好**：支持 JSON 输出、稳定退出码，以及正文参数、stdin、UTF-8 文本文件三种输入来源。

当前支持本地 Windows 文件系统和单写者使用；网络共享不作兼容性承诺。`descript.ion` 必须是带 BOM 的 UTF-8 文件。

## 快速上手

将 `dion.exe` 放在当前目录，在 PowerShell 中运行。下面假设 `报告.txt` 和 `资料` 文件夹已存在：

```powershell
# 设置文件备注
.\dion.exe set '.\报告.txt' '项目验收报告'

# 查看文件备注
.\dion.exe get '.\报告.txt'

# 设置文件夹自身的备注
.\dion.exe set '.\资料' '项目参考资料'

# 列出当前目录的备注
.\dion.exe list

# 单栏阅读完整多行正文
.\dion.exe list --long

# 列出资料文件夹内部条目的备注
.\dion.exe list '.\资料'

# 递归汇总资料目录的备注，名称相对于资料目录
.\dion.exe list '.\资料' -r

# 递归单栏阅读，或输出 JSON
.\dion.exe list '.\资料' --recursive --long
.\dion.exe list '.\资料' -r --json

# 从 UTF-8 文本文件读取多行备注
.\dion.exe set '.\报告.txt' --comment-file '.\备注.txt'

# 输出 JSON，方便脚本处理
.\dion.exe get '.\报告.txt' --json

# 删除备注
.\dion.exe remove '.\报告.txt'
```

`set` 要求目标文件或文件夹存在，拒绝空白正文；首次设置会自动创建备注文件。`get/set/remove` 操作条目自身的备注，`list` 列出目录内部的备注。删除最后一条记录时，备注文件也会删除。

默认 `set/remove` 成功时不输出文字，`get` 只输出正文。正文参数中的字面量 `\n` 不会变成换行；多行内容推荐通过 `--comment-file` 输入，正文文件接受带或不带 BOM 的 UTF-8。

`list` 默认只查询指定目录；加 `--recursive` 或 `-r` 时递归汇总子目录。目录（包括目录链接及 Junction）优先，组内按 Windows 不区分大小写自然升序显示，孤立记录仍会列出。排序只改变输出，不改写备注文件。默认双栏按名称显示宽度对齐，多行正文后续行对齐右栏，例如：

```text
docs\       文档目录
file2.txt   第一行
            第二行
file10.txt  第十份
```

`list -l` 与 `list --long` 等价：名称独占一行，每行正文缩进四个空格，记录之间增加一个空行。两种文本模式保留完整正文、空行和末尾换行，不截断或主动折行。`list --json` 使用相同排序，保留 `entries`、`name`、`comment`、`extension` 字段，名称不带目录标记；加上 `--long` 也不会改变 JSON 内容。

递归时每个目录先输出自身全部已排序记录，再按子目录名称自然升序逐个深度优先遍历；不会重新按完整路径排序。名称使用相对于起始目录的 Windows 路径，例如 `子目录\报告.txt`，起始目录的名称不加点前缀。双栏宽度按整个结果计算，单栏和 JSON 共用相同记录顺序。

没有备注文件的中间目录仍会遍历。途中遇到的目录符号链接和 Junction 不进入，但其自身备注仍列出；显式指定它们为起始目录时会读取内部。其他目录重解析点不额外排除。非普通记录名称保持完整，不据此访问路径或构造层级。任一目录访问或备注格式、编码错误都会使整次查询失败，stdout 为空。

## 性能测试

2026-10-08 在 Windows 11 x64、AMD Ryzen 9 7940H、31.2 GB 内存的本地环境中测得以下 Release 基线。每个场景预热后运行 5 次，表中为平均壁钟耗时，包含进程启动和退出；查询与列表使用文本输出。

| 操作 | 100 条记录 | 10,000 条记录 |
| --- | ---: | ---: |
| 查看备注 `get` | 167.73 ms | 148.14 ms |
| 列出备注 `list` | 154.01 ms | 207.29 ms |
| 更新备注 `set` | 167.12 ms | 167.78 ms |
| 删除备注 `remove` | 208.08 ms | 217.87 ms |

本次 exe 体积为 **354,816 字节（346.5 KiB）**；温运行场景的生命周期峰值提交量为 9.26–18.17 MiB。结果仅代表本次机器与工作负载，不构成固定时延保证。完整数据、测量口径与复现方法见[性能测试报告](docs/benchmarks.md)。
