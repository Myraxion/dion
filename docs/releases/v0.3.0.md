Dion v0.3.0 加快递归列表查询，并新增使用 Everything 索引查找递归备注文件的可选方式。

## 下载与使用

- 支持 Windows 10/11 x64，本地文件系统、单写者使用。
- 下载附件中的 [dion.exe](https://github.com/Myraxion/dion/releases/download/v0.3.0/dion.exe)，无需安装 Rust 或额外运行库。
- 在 PowerShell 中运行 `.\dion.exe --help` 查看帮助；默认跟随 Windows 用户界面语言，支持简体中文，其他语言使用英文。

## 新增与改进

- **Everything 索引查询**：`list --recursive --everything` 或 `list --tree --everything` 可通过已运行的 Everything 索引发现递归范围内的 `descript.ion` 文件；支持双栏、单栏、树和 JSON 输出。默认优先连接 `1.5a` 实例，再尝试未命名实例；可用 `--everything-instance <name>` 指定命名实例。
- **递归列表提速**：普通递归在目录枚举中未发现 `descript.ion` 时不再额外尝试打开该文件。
- **默认跳过常见目录**：递归列表默认跳过 `$RECYCLE.BIN`、`System Volume Information`、`.git`、`node_modules`、`.venv`、`__pycache__`、`.pytest_cache`、`.next`、`.svn`、`.mypy_cache`、`.ruff_cache`、`.tox`、`.nox` 和 `.parcel-cache`，避免遍历无关子树。

## 使用说明

- Everything 查询只覆盖当前索引中的路径，索引排除或尚未收录的备注文件可能遗漏；未访问目录的遍历错误不会报告。要求 Everything 1.4.1 或更高版本运行且数据库已加载。
- Everything 连接或查询失败时会直接报错，不会回退到普通目录扫描。若要按普通目录遍历查询，请移除 `--everything`；如需包含默认跳过的目录，再加 `--all`。
- `--everything` 必须与 `--recursive` 或 `--tree` 组合。`--all`（`-a`）可包含默认跳过的目录；这些目录自身的备注仍会正常列出。
- 递归过程中仍不进入子目录中的目录符号链接或 Junction。
