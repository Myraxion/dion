Dion v0.3.2 新增版本查询，方便确认当前运行的程序版本和排查升级、PATH 或脚本问题。

## 下载与使用

- 支持 Windows 10/11 x64，本地文件系统、单写者使用。
- 下载附件中的 [dion.exe](https://github.com/Myraxion/dion/releases/download/v0.3.2/dion.exe)，无需安装 Rust 或额外运行库。
- 在 PowerShell 中运行 `.\dion.exe --version` 或 `.\dion.exe -V` 查询版本，本版本输出 `dion 0.3.2`。
- 运行 `.\dion.exe --help` 查看帮助；默认跟随 Windows 用户界面语言，支持简体中文，其他语言使用英文。

## 版本查询

- `--version` 与 `-V` 等价，版本号取自编译时的包版本。成功时向 stdout 输出一行版本文本，stderr 为空，退出码为 0。
- 可搭配 `--json/-j`、`--lang`，版本输出始终为同一行文本。
- 与操作命令、操作选项或帮助混用时报 `invalid_argument`，退出码为 2；未知、重复及无效语言选项继续按现有规则校验。
- `--` 后的 `--version`、`-V` 仍作为普通路径或备注正文。
- 中英文总览帮助与 README 已同步说明版本查询。

## 验证

- Windows 统一检查入口通过格式检查、Clippy、完整 173 项测试和 Release 构建。
- 新增真实 CLI 测试覆盖版本输出、参数组合、备注文件保持和分隔符语义。
- 本地 Release 程序实测版本输出为 `dion 0.3.2`，包括搭配 JSON 和中文语言选项的调用。
