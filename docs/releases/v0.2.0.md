Dion v0.2.0 改善列表查询、终端展示与命令输入，并新增英文和简体中文文案。

## 下载与使用

- 支持 Windows 10/11 x64，本地文件系统、单写者使用。
- 下载附件中的 [dion.exe](https://github.com/Myraxion/dion/releases/download/v0.2.0/dion.exe)，无需安装 Rust 或额外运行库。
- 在 PowerShell 中运行 `.\dion.exe --help` 查看帮助；默认跟随 Windows 用户界面语言，支持简体中文，其他语言使用英文。

## 新增与改进

- **列表容错**：`list` 遇到坏记录或无法读取的备注文件时，保留有效记录并汇总错误；递归过程中无法访问的子目录会跳过，继续查询其他目录。起始目录无法访问时仍直接失败。
- **命令简写**：新增 `get` 的别名 `view`、`cat`，`list` 的别名 `ls`，`remove` 的别名 `rm`、`unset`、`del`；支持 `-j`、`-h`、`-l`、`-r`、`-t`、`-i`、`-f`、`-e` 等短选项。别名与完整命令行为相同，短选项需分开输入。
- **终端着色**：列表名称、目录标记和树状连接符显示为青色，备注正文保持原样。默认在支持颜色的终端自动启用；使用 `--color auto|always|never` 控制，自动模式遵循 `NO_COLOR`，JSON 不添加颜色序列。
- **中英文文案**：帮助、参数错误、操作错误和列表错误汇总支持英文与简体中文；新增英文 README。用户备注与文件名保持原样。
- **Windows 名称比较**：名称匹配和重复检测统一使用 Windows 原生、不区分大小写的序数比较；保留记录原拼写，列表继续按目录优先、自然排序展示。

## 修复

- 修复树状列表中带多行备注的目录与子节点之间垂直连接线中断的问题。

## 升级注意

- `list --json` 的结果新增 `errors` 数组，无错误时为 `[]`。跳过错误时仍输出 `entries` 和 `errors`，退出码为 `1`；脚本应同时检查退出码与错误数组。
- 列表跳过的错误与有效结果共同写入 stdout；文本模式在列表末尾汇总错误。
- JSON 错误的 `message` 会随程序语言变化；字段名、错误代码和退出码保持稳定，脚本应按 `code` 判断错误。
- 名称等价关系由 Rust Unicode 小写转换改为 Windows 原生比较，部分 Unicode 名称的匹配及重复判定可能变化；不进行 Unicode 规范化，也不跟随目录的大小写敏感设置。
