# 使用同目录临时文件提交，第一版限定单写者

Dion 在同目录写完整临时文件后提交替换，不直接截断原备注文件，也不在替换失败后回退为原地覆盖。第一版的 UNC 支持声明限定为经过验收的 Windows SMB 环境，按单写者使用，不保证多个进程或多台机器同时修改同一备注文件；检测到占用或内容变化时报错，不自动重试或合并。

此方案优先覆盖轻量的备注编辑场景，避免引入跨机器协调协议；内容变化检测只是冲突发现手段，并非完整并发保证。格式和输入校验失败不修改文件，但 Windows 文件提交存在部分失败状态，不能将本方案描述为所有本地或 UNC 故障下均可回滚的事务。

2026-10-07 根据实际验收收紧支持声明：Windows SMB 本机回环已通过；两种 WebDAV 服务分别出现元数据不符合契约、写入/删除失败等限制，不能因路径为 UNC 就承诺兼容。保留现有文件操作和提交规则，不为 WebDAV 增加原地覆盖、自动重试或单独的 UNC 模块。独立远端 Windows SMB、Samba/NAS 和网络中断场景的验证状态见 [UNC 验证](../unc-validation.md)。
