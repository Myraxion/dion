# 使用同目录临时文件提交，第一版限定单写者

Dion 在同目录写完整临时文件后提交替换，不直接截断原备注文件，也不在替换失败后回退为原地覆盖。第一版支持范围为本地 Windows 文件系统，按单写者使用，不保证多个进程同时修改同一备注文件；检测到占用或内容变化时报错，不自动重试或合并。

此方案优先覆盖轻量的备注编辑场景，避免引入并发协调协议；内容变化检测只是冲突发现手段，并非完整并发保证。格式和输入校验失败不修改文件，但 Windows 文件提交存在部分失败状态，不能将本方案描述为所有 I/O 故障下均可回滚的事务。

2026-10-08 用户决定移除 UNC 支持承诺、专用共享测试和验收入口，以减少第一版的维护与验收范围。保留现有文件操作、本地长路径处理和提交规则，不新增路径拒绝或网络存储检测。UNC 和网络映射盘可能被现有接口接受，但不保证兼容；网络共享不再阻塞第一版交付。此前的共享实测仅作[历史记录](../archive/unc-validation.md)。
