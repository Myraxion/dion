# 人读诊断跟随语言，机器契约使用稳定代码

2026-10-10，用户确认 Dion 的文本诊断和 JSON `message` 均跟随所选语言，而 JSON 字段名、错误代码及退出码保持稳定。选择统一的人读文案，而不是把 JSON 文案固定为英文，是为了让 JSON 中的错误说明也能供当前用户阅读；脚本必须根据 `code` 判断错误，需要英文诊断时显式指定英文，不能把 `message` 的具体措辞作为机器契约。

Dion 翻译自己的上下文，保留底层系统错误原文、路径和错误编号，因此诊断允许混合语言。界面语言只影响程序文案，不改变用户备注、名称、备注文件或名称匹配与排序规则。完整范围和验收记录见[多语言支持设计](../archive/multilingual-design.md)，当前行为以[行为契约](../spec.md)为准。
