# 列表只输出名称与备注，单条查询保留程序扩展类型

2026-10-13，用户确认 `list --json` 用于列出名称与解析后的备注正文，每条记录只保留 `name`、`comment`，继续输出 `errors`，未知程序扩展记录仍正常列出。选择精简列表而不是保留存储格式信息，代价是列表消费者不能再据此预判未知程序扩展的非空修改限制；需要检查单条记录的程序扩展类型时使用 `get --json`，实际修改仍遵循既有校验规则。

`get --json` 将 `extension` 改名为 `program_extension`，沿用领域术语“程序扩展”，避免与文件扩展名混淆；值仍为 `none`、`tc`、`unknown`。这是明确接受的 JSON 破坏性变更，直接调整契约并在发布说明中记录，不保留旧字段别名或新增兼容开关。备注解析与写入规则不变。
