## 结果分析与时延门槛说明

- 本次 exe 体积为 0.34 MiB，5 MiB 目标：**达成**。
- 100 条记录温运行：各场景平均壁钟耗时 153.82–208.08 ms，平均 CPU 耗时 106.25–121.88 ms，峰值提交量 9.26–9.35 MiB。
- 10,000 条记录温运行：各场景平均壁钟耗时 148.14–217.87 ms，平均 CPU 耗时 106.25–162.50 ms，峰值提交量 11.02–18.17 MiB。
- 上述区间为本次场景统计值的最小值与最大值，不是单次运行范围或性能保证；峰值内存结果不能证明不存在内存泄漏。
- 旧版报告使用 Job Object 峰值且混称工作集，本次统一为进程峰值提交量；不将两种口径的数值直接用于判断性能变化。
- 保留本地基线供后续确认时延预算，本次不新增固定时延门槛。
