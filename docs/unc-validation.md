# UNC 验证（Issue #9）

## 支持范围与验收状态

2026-10-07 用户确认：保留 UNC 路径操作，第一版支持声明限定为经过验收的 Windows SMB 环境。UNC 是路径形式，不是服务兼容性保证。继续复用现有文件操作与提交规则，不增加独立 UNC 模块，不为 WebDAV 增加原地覆盖、自动重试或合并回退。

| 环境 | 状态 |
| --- | --- |
| Windows SMB 本机回环 | 五个真实共享用例通过，65 个本地集成测试及统一检查通过 |
| 独立远端 Windows SMB | 待验收，当前没有可用的独立服务端；Issue #9 的验收待办尚未全部完成 |
| Samba/NAS | 尚未验收，不声明兼容 |
| WebDAV | 两个服务已实测，均未满足完整契约，不在支持声明内 |
| WinFsp 挂载盘 | 不替代 SMB 验收，未进行功能验收 |

## 运行

测试启动真实 Dion CLI，在指定共享目录下建立随机 `dion-unc-*` 子目录，正常结束后删除隔离数据。需要当前用户对共享和测试目录有创建、读取、写入、删除以及修改测试文件 DACL 的权限；属性与权限测试针对支持 Windows 文件属性和 DACL 的服务器。不新增共享、不修改共享配置，也不修改共享根备注文件。

```powershell
$env:DION_UNC_ROOT = '\\server\share\test'
.\scripts\check.ps1
# 或仅运行真实 UNC 用例
cargo test --locked --test unc -- --ignored --nocapture
```

`DION_UNC_ROOT` 必须是普通或扩展 UNC 路径；SMB 验收还需确认后端确实是 Windows SMB，路径检查本身不验证协议。测试不会接受本地目录或映射盘作为替代；指定但不可用的环境会使测试失败。未指定环境时统一检查跳过这些显式 ignored 用例并输出 `UNVERIFIED`，本地测试通过不表示 UNC 验证通过。共享根测试会只读列出该共享根已有的备注文件；若它格式非法，测试会失败，需要使用专用测试共享。权限测试只更改随机测试文件的 DACL，并在断言前恢复。

## 已执行环境与结果（2026-10-07）

- 客户端和服务端：同一台 Windows 11 IoT 企业版 LTSC，版本 `10.0.26100`；通过现有 Windows SMB 服务访问 `\\localhost\D$\Workspace\code\dion\.scratch`，不是将本地路径冒充 UNC。
- 用户：`asustufx4\miaojr`。D$ 共享允许 Administrators、Backup Operators 和 INTERACTIVE 完全访问；测试文件继承工作区 NTFS 权限，替换测试设置保护 DACL，拒绝访问测试针对当前用户添加 ReadData deny 并恢复。
- `Get-SmbConnection` 查询被系统拒绝，因此未记录协商的 SMB dialect，不推断其版本。
- 用户提供的 `\\cryptomator-vault\lD0mlXGA7bQM\test` 在沙箱外返回 Windows 错误 53（找不到网络路径），未通过读写验收。随后确认实际路径为 `X:\test`，是 WinFsp 挂载；它不能替代真实 UNC 网络共享验证。
- 沙箱内 SMB 操作曾返回错误 65（拒绝网络访问），格式化也受路径访问限制；真实验收在沙箱外执行。这些环境错误不作为产品行为的 red → green 证据。

五个真实共享用例验证：

1. 普通 UNC 与 `\\?\UNC\...`、超过 260 字符的 Unicode 路径；三种输入来源、多行及尾部空行、正文文件的 UTF-8 BOM；get/list 文本和 JSON、写操作 changed、退出码与 stderr；首次创建的字节与隐藏属性、替换的属性/创建时间/保护 DACL、条目属性不变、最后记录删除及重复删除、成功无临时文件残留。
2. 实际共享根支持 list，get/set/remove 对根返回参数错误。
3. 独占文件时四命令报操作错误；拒绝删除共享方式使替换失败时原字节保留，同目录完整临时文件仍存在，诊断给出目标及实际恢复文件位置；多记录 remove 也覆盖替换失败。只读修改和最后记录删除报错，读取成功；最后记录被占用时拒绝删除。
4. 在已可访问服务器上请求不存在的共享，普通和扩展 UNC 的四命令都返回 `io_error`、退出码 1 且正常 stdout 为空。
5. 实际文件 DACL 拒绝当前用户读取时，四命令均返回操作错误，不能伪装为空列表、缺失记录或成功删除；恢复权限后原始字节不变。

这些是对现有行为补充的验收覆盖，在上述 Windows SMB 回环范围内没有发现需要修改生产代码的问题，不声称功能 red → green。

## WebDAV 实测摘要（2026-10-07）

两次均使用现有 Windows WebDAV 连接和真实 CLI，在用户指定目录下创建随机隔离测试目录。服务端系统及后端实现未确认；未修改已有内容或服务配置，测试目录均已清理。运行前后真实顶层条目的名称、长度、属性及修改时间差异为 0；这不是对整个服务器进行内容哈希校验。

- `\\webdav.majorman.org@SSL\DavWWWRoot`：在其 `新建文件夹` 下测试。普通和扩展 UNC、三种输入来源的短 Unicode 路径共 42 次 Release CLI 操作成功，多行往返和最后记录删除检查通过；但新备注文件显示为 Archive，没有隐藏属性，创建时间返回 1601 年。ACL 准备操作返回 `Incorrect function`，长路径准备返回错误 206，未进入对应 CLI 验收。因此基本内容操作可用不代表完整契约成立。
- `\\app.koofr.net@SSL\DavWWWRoot\dav\Koofr`：普通和扩展 UNC 可以读取手工准备的多行备注；三种来源的六次首次设置，以及已有记录替换、部分删除和最后记录删除的六次操作均返回 `io_error` / Windows 错误 3。替换与部分删除失败后原备注字节不变。ASCII、纯中文普通文件可直接写入，Emoji 文件名准备返回错误 31；不含 Emoji 的 341 字符路径可直接创建普通文件，但 Dion 设置仍失败。ACL 准备操作不支持。错误结果不作为具体根因结论。

两处原有五项 UNC 测试均为三项通过、两项在环境准备阶段失败。故障诊断测试通过不能解释为正常创建、替换、删除或元数据保留通过；WebDAV 的结果不计入 SMB 验收。

## 限制

本机 SMB 回环已经实际经过共享服务，但不代表其他机器、Samba/NAS、其他权限配置或网络链路已验证。远端服务器、服务器不支持替换、真实提交中途断网/断电和部分完成状态未实测；占用导致的替换失败不代表这些场景。第一版仍为单写者，不重试、不合并，不承诺完整回滚；失败时需要检查诊断中的备注文件及仍存在的恢复文件。
