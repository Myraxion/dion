# 命令别名与参数简写设计（设计档案）

> [!NOTE]
> **设计档案声明**：
> 本文记录命令别名与参数短选项的设计决策与规则。相关功能已全面实施并随 v0.2.0 交付。当前系统的外部行为契约完全以 [行为契约 (spec.md)](../spec.md) 为准。

## 目标

减少常用操作的输入量，通过固定的命令别名与短选项提供更方便的 CLI 输入方式。

## 已确认规则

- 保留现有完整命令名、长选项和行为；新增写法作为等价入口，现有脚本无需修改。
- 命令别名与参数短选项均明确指定，只接受预先定义的写法，不自动识别任意前缀。
- 保留已有 `--help/-h`、`--long/-l`、`--recursive/-r`；新增 `--json/-j`、`--tree/-t`、`--stdin/-i`、`--comment-file <file>/-f <file>`、`--edit/-e`。
- 保持选项按独立参数输入，不增加短选项连写、选项与值紧连或等号传值。

## 命令别名

| 完整命令 | 别名 |
| --- | --- |
| `get` | `view`、`cat` |
| `list` | `ls` |
| `set` | 无 |
| `remove` | `rm`、`unset`、`del` |

`get` 的单字母 `g` 含义不够直观，改用表达查看的 `view` 和符合文本输出习惯的 `cat`。`list` 使用常见写法 `ls`；`set` 已足够短，不增加单字母 `s`。删除别名均删除备注，行为与 `remove` 相同。

## 帮助与兼容性

- 全部命令别名支持 `help <别名>`、`<别名> --help` 和 `<别名> -h`，返回对应完整命令的同一份帮助。
- 帮助与 README 列出全部别名及短选项；帮助按所选语言输出，不添加示例。
- 重复同义选项继续报错；互斥规则、选项的命令范围、`--` 分隔符、JSON 输出和退出码沿用既有行为。
- 别名只在命令及帮助主题位置识别，路径、正文和正文文件名保持原值。

## 验收范围

真实 CLI 验证全部命令别名的操作和帮助等价性、新短选项成功路径、JSON 参数及操作错误、重复和互斥选项、选项范围、`--` 后的字面值及不支持的紧凑写法。执行统一检查入口 `scripts/check.ps1`。
