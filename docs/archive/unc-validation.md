# 网络共享实测历史记录

2026-10-08 用户决定移除 UNC 支持承诺、专用共享测试和验收入口。[Issue #9](https://github.com/Myraxion/dion/issues/9) 按取消范围处理，不代表完整兼容性验收通过。以下为 2026-10-07 的历史结果，不属于当前支持范围、待办或发布门槛；原来的测试命令和环境变量入口已移除。

## Windows SMB 本机回环

客户端和服务端是同一台 Windows 11 IoT 企业版 LTSC，版本 `10.0.26100`，通过现有 SMB 服务访问 `\\localhost\D$\Workspace\code\dion\.scratch`。当前用户具有共享及工作区文件访问权限；权限用例仅修改随机测试文件的 DACL。SMB dialect 查询被拒绝，未记录协商版本。

五项真实共享测试通过：普通与扩展长 UNC、Unicode 和三种输入、四命令及机器输出、隐藏创建和替换元数据、共享根边界、占用及只读、失败恢复文件、不可访问共享与实际 DACL 拒绝。同时 65 个本地集成测试及统一检查通过。独立远端 Windows SMB、Samba/NAS、提交中途断网/断电和部分完成状态未实测。

## WebDAV

两次均使用现有 Windows 连接和真实 CLI，在用户指定目录下创建随机隔离测试目录。服务端系统及后端实现未确认；测试目录均已清理。运行前后真实顶层条目的名称、长度、属性及修改时间差异为 0；这不是对整个服务器进行内容哈希校验。

- `\\webdav.majorman.org@SSL\DavWWWRoot`：在其 `新建文件夹` 下测试。短 Unicode 路径、普通和扩展 UNC、三种输入的 42 次 Release CLI 内容操作成功；多行往返和最后记录删除通过。但新备注文件没有隐藏属性，创建时间返回 1601 年；ACL 准备返回 `Incorrect function`，长路径准备返回错误 206。
- `\\app.koofr.net@SSL\DavWWWRoot\dav\Koofr`：普通和扩展 UNC 可以读取手工准备的多行备注；六次首次设置和六次已有记录写删均返回 `io_error` / Windows 错误 3。替换与部分删除失败后原字节不变。ASCII 和纯中文普通文件可直接写入，Emoji 文件名准备返回错误 31；不含 Emoji 的 341 字符路径可创建普通文件，但 Dion 设置仍失败。ACL 准备不支持。错误结果不作为具体根因结论。

两处原有五项共享测试均为三项通过、两项在环境准备阶段失败。故障诊断成功不代表正常创建、替换、删除或元数据保留通过。

## 其他环境与限制

用户提供的 `\\cryptomator-vault\lD0mlXGA7bQM\test` 返回 Windows 错误 53；随后确认实际地址是 `X:\test`，为 WinFsp 挂载，未作功能验收。

这些历史实验不能证明任意网络服务兼容，也不提供跨机器并发保证或故障下完整回滚保证。
